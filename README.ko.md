# 오픈 보행 안전 헬멧 (Open Walking Safety Helmet)

[English](README.md) · **한국어**

> ### 전 세계 시각장애인이 일반인처럼 다닐 수 있는 그날까지.

시각장애인과 저시력인이 안전하게 걸을 수 있도록 돕는 오픈소스 헬멧입니다.
**머리 높이의 장애물**을 감지하고, **계단과 낭떠러지**를 찾고, **다가오는 자전거·자동차·사람**을 알려줍니다.
**표지판을 읽어주고**, **아는 사람의 얼굴**을 알아보며, 위급할 때는 **위치와 함께 SOS**를 보냅니다.
알림은 **머리에 닿는 진동**과 **음성**으로 전달됩니다.

펌웨어, 3D 프린팅 부품, 배선도, 휴대폰 앱, 문서, 그리고 **특허까지 모두 무료로 공개**합니다.

**발명자·프로젝트 책임자:** 씨엘소프트랩(CLSOFTLAB) 이일국 박사
**특허:** 대한민국 등록특허 제10-2560496호. 누구나 무상으로 실시할 수 있습니다. 자세한 내용은 [특허 무상 실시 선언](PATENT_PLEDGE.md)을 보세요.

> [!WARNING]
> **현재 상태: v1.0 기준 설계이며, 아직 현장 검증 전입니다.** 이 헬멧은 보조기기이고 인증된 의료기기가 아닙니다.
> 흰지팡이, 안내견, 보행 훈련을 **대신하지 않습니다.** 실제로 걷기 전에 [안전수칙](docs/ko/06-안전수칙.md)을 꼭 읽어 주세요.

## 왜 안경이 아니라 헬멧인가요?

센서도 놓칠 때가 있습니다. 그래도 부딪히는 순간 **헬멧은 머리를 지켜줍니다.**
그래서 이 프로젝트는 헬멧의 보호 성능을 절대 해치지 않도록 설계했습니다.

- **인증받은 자전거 헬멧**을 그대로 씁니다. 헬멧 껍데기를 3D 프린팅하지 않습니다.
- 헬멧에 **구멍을 뚫거나, 자르거나, 접착하지 않습니다.**
- 모듈은 **스트랩과 탈착식 패드**로 붙여서, 충격을 받으면 떨어져 나가게 합니다.
- 모듈 바닥을 헬멧 곡면에 맞춰 밀착시키고, 튀어나온 높이는 35~40mm 이하(작은 모듈은 30mm 이하), 모서리는 모두 둥글게 처리합니다.

## 무엇을 해주나요?

| 이렇게 느끼거나 들으면 | 이런 상황입니다 |
|---|---|
| 이마 진동이 점점 빨라지다가 계속 울림 | 앞에 **머리 높이 장애물**(나뭇가지, 간판, 트럭 사이드미러)이 있음. 2m → 1.2m → 0.6m |
| 진동 3개가 길게 두 번 + "앞에 내려가는 계단" | **내려가는 계단, 턱, 승강장 끝** |
| 왼쪽 또는 오른쪽 진동 + "오른쪽에서 자전거 접근" | 사람·자전거·자동차가 **나에게 다가옴** |
| 한쪽에 부드러운 진동 두 번 + "민아 님이 왼쪽 앞에 있어요" | **등록한 지인**이 근처에 있음 |
| ○ 버튼 누르기 | 앞에 있는 **글자를 읽어줌** (표지판, 안내문) |
| △ 버튼 누르기 | **주변 설명**: "앞에 사람 2명, 오른쪽에 자전거" |
| □ 버튼 3초 누르기, 또는 넘어짐 | **SOS** 카운트다운 후, 휴대폰 앱에 위치와 전화·문자 버튼이 뜸 |
| 10초마다 이마에 짧은 진동 3번 | **어딘가 고장입니다.** 조용하다고 안전한 게 아닙니다. 거리 센서는 계속 작동합니다. |

진동 신호 전체 설명은 [사용자 가이드](docs/ko/05-사용자가이드.md)에 있습니다.

## 어떻게 작동하나요?

```
 광각 카메라 ─► 물체 검출 · 추적 · 충돌 예상 시간 ─────────────┐
               얼굴 인식 · 글자 읽기 (요청 시)                  │
 전방 라이다 ─► 머리 높이 장애물 거리 구간 (AI 없이도 작동) ────┼─► 우선순위 판단 ─► 진동모터 3개
 하향 라이다 ─► 계단 · 낭떠러지 · 턱 감지                       │                └► 음성 (귀를 막지 않는 헤드셋)
 IMU        ─► 넘어짐 감지                                     │                └► 휴대폰 앱 (BLE): 위치 · SOS
 버튼 ○△□   ─► 읽기 · 설명 · 상태 / SOS ────────────────────────┘
 감시 기능: 모든 센서를 지켜보다가 고장이 나면 알려줌
```

- 라즈베리파이 5 **CPU만으로, 인터넷 없이** 작동합니다. GPU도 클라우드도 필요 없습니다.
- **안전 경고는 AI에 의존하지 않습니다.** 카메라나 인공지능이 멈춰도 라이다 경고는 계속 작동합니다.
- **얼굴 정보는 헬멧 밖으로 나가지 않습니다.**

전체 구조와 모든 수치는 [시스템 설계서](docs/ko/00-시스템설계서.md)에 있습니다.

## 하드웨어 구성

라즈베리파이 5 · 카메라 모듈 3 광각 · TF-Luna 라이다 2개 · MPU-6050 IMU · 동전형 진동모터 3개 + ULN2003 ·
촉각 버튼 3개 · USB 오디오 + 오픈형 헤드셋 · 주머니에 넣는 USB-C 보조배터리 · 인증 자전거 헬멧 · 3D 프린팅 PETG/TPU 부품.

기본 구성은 **납땜이 필요 없고**, 모든 부품은 220×220mm 프린터로 출력할 수 있습니다.
부품과 예상 비용은 [부품목록](docs/ko/01-부품목록.md), 실제 구매 링크와 잘못 사기 쉬운 부품은 **[구매 가이드](docs/ko/10-구매가이드.md)**를 보세요. 디바이스마트·엘레파츠 장바구니 단위로 정리해 두었습니다.

## 시작하기

**1. PC에서 체험하기 (하드웨어 없이)**

```bash
cd firmware
pip install -e .[dev]
python -m owsh.tools.download_models
python -m owsh --sim --video 보행영상.mp4
```

화면에 검출 결과, 진동모터 3개의 세기 막대, 가상 라이다 값이 나옵니다. 키보드 조작법은 [firmware/README.md](firmware/README.md)에 있습니다.

**2. 헬멧 만들기:**
[부품목록](docs/ko/01-부품목록.md) → [구매 가이드](docs/ko/10-구매가이드.md) → [3D 프린팅](docs/ko/03-3D프린팅가이드.md) → [배선](docs/ko/02-배선가이드.md) → [조립과 설정](docs/ko/04-조립가이드.md) → [시험계획](docs/ko/07-시험계획.md)

**3. 휴대폰 앱:** 안드로이드 크롬에서 HTTPS로 [`app/`](app/)을 열면 됩니다. 헬멧이 없어도 내장된 데모 헬멧으로 먼저 써볼 수 있습니다.

## 전 세계의 참여를 기다립니다

이 프로젝트는 실제로 쓰는 사람들이 세계 곳곳에서 시험하고 고쳐 나갈 때 비로소 완성됩니다.

- **시각장애인 보행자와 보행 교사:** 현장 시험과 솔직한 의견
- **메이커:** 직접 만들어 보고, 거치 방식을 개선하고, 더 싼 부품을 찾아 주세요
- **번역가:** 여러분의 언어로 음성 안내를 만들어 주세요. 안전 문구는 그 언어를 쓰는 시각장애인의 검토가 필요합니다 ([번역 가이드](docs/ko/09-번역가이드.md))
- **머신러닝 엔지니어:** 점자블록, 횡단보도, 경사로, 엘리베이터 버튼 데이터셋과 검출 모델
- **개발자:** 펌웨어, 자동 SOS가 되는 안드로이드·iOS 앱, 길 안내

참여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md), 앞으로의 계획은 [특허와 로드맵](docs/ko/08-특허와로드맵.md)에 있습니다.

## 이야기

이일국 박사는 시각장애인이 안전하게 걸을 수 있기를 바라며 2021년 이 발명을 출원했고, 2023년 대한민국 특허로 등록받았습니다.
예전에는 이 모든 시스템을 혼자 만든다는 건 꿈도 꾸기 어려운 일이었습니다. 하지만 Claude 같은 AI와 함께라면 설계부터 소프트웨어, 공개까지 해낼 수 있는 세상이 되었습니다.
그래서 이 발명을 전 세계에 무료로 내놓습니다. 씨엘소프트랩과 이일국 박사가 앞으로도 계속 개발해 나가겠습니다.
