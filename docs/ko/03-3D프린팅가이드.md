**권장 출력 순서.** 먼저 `button_caps`와 `strap_anchor` 하나를 출력하세요. 작아서 빨리 끝나고, 끼워 맞춤과
출력 설정이 맞는지 확인할 수 있습니다. 그다음 헬멧을 재고(다음 장), 그 값으로 곡면 부품을 렌더링해서 출력합니다.

## 2. 헬멧부터 재기

전방 센서 포드, 메인 케이스, 보조 포드는 외피를 따라가는 **곡면 바닥면**을 가지고 있습니다. 각 모듈은 두께가
고른 **3 mm TPU 새들** 위에 놓이며, 받침 다리도 없고 5 mm가 넘는 틈도 없어야 합니다(설계서 P2). 곡면은 출력할
때 정해지므로, 이 부품들을 **출력하기 전에 헬멧을 재야 합니다.** 설계 범위는 국소 반경 **95–130 mm**입니다
(설계서 §4.4).

### 외피 곡률 반경 재는 법

곧은 자(또는 곧은 모서리가 있는 물건)와 캘리퍼스가 필요합니다.

1. 모듈이 놓일 바로 그 자리에 자를 외피 위에 걸쳐 놓습니다.
2. 자가 외피에 닿는 두 점 사이의 **현 길이** `L`을 읽습니다. 예: 100 mm.
3. 자의 가운데에서 외피까지 수직으로 **틈** `h`를 잽니다. 예: 11 mm.
4. 계산합니다: **R ≈ L² ÷ (8 × h)**. 예: 100² ÷ (8 × 11) ≈ **114 mm**.
5. 위치마다 머리를 **가로지르는 방향**(왼쪽에서 오른쪽)과 **따라가는 방향**(앞에서 뒤)으로 모두 잽니다.
   따라가는 방향 값이 보통 더 큽니다.

설계서는 이 두 값을 `helmet_radius`(가로)와 `helmet_radius_long`(세로)라고 부릅니다. 이 값은 공통 기본값으로
[`hardware/openscad/lib/owsh_common.scad`](../../hardware/openscad/lib/owsh_common.scad)에 들어 있습니다.
**v1.1 모델에서는 모듈마다 자기 파라미터가 따로 있고, 실제로 부품 모양을 정하는 것은 이 파라미터입니다.**

| 파라미터 | 파일 | 기본값 | 재는 곳 |
|---|---|---|---|
| `pod_R` | `lib/front_pod_lib.scad` | 110 mm | 전방 센서 포드 밑, 머리를 가로지르는 방향 |
| `mount_pitch_deg` | `lib/front_pod_lib.scad` | 30° | 머리를 수평으로 두었을 때 포드 밑 외피의 경사(휴대폰 기울기 앱). 센서 각도는 이 값으로 보정됩니다. |
| `case_R_lat`, `case_R_long` | `lib/main_case_lib.scad` | 110 / 140 mm | 메인 케이스 밑, 가로 / 세로 |
| `aux_R_lat`, `aux_R_long` | `lib/aux_pod_lib.scad` | 110 / 140 mm | 보조 포드 밑, 뒤통수를 둘러싸는 방향 / 위로 올라가는 방향 |
| `side_R` | `button_module.scad` | 140 mm | 오른쪽 귀 위, 외피를 따라가는 방향 |
| `saddle_t` | `lib/owsh_common.scad` | 3 mm | 새들 두께 (≤ 4 mm 유지) |
| `clr` | `lib/owsh_common.scad` | 0.3 mm | 한쪽당 끼워 맞춤 여유 |

파일을 고치지 않고 명령줄에서 값을 바꿀 수 있습니다. 예:

```bash
openscad -D pod_R=114 -D mount_pitch_deg=25 -o hardware/stl/front_pod_base.stl hardware/openscad/front_pod_base.scad
```

또는 라이브러리 파일 맨 위의 값을 직접 고친 뒤 다시 렌더링하세요. 모듈의 반경 값을 바꿨다면 그 모듈의 부품
**두 개 모두**(바닥과 뚜껑 또는 덮개)와 `saddle_pad` 판을 다시 렌더링합니다. 내 반경 값이 기본값과 많이
다르다면 포드 양 끝 아래의 틈을 확인하세요. 모양이 아주 다른 외피에서는 틈이 생길 수 있습니다.

머리를 가로지르는 방향으로 잰 값이 95–130 mm를 벗어나면 그 헬멧은 설계 범위 밖입니다. 더 둥근 헬멧을 고르거나,
맞춤 상태를 아주 꼼꼼히 확인하고 이슈로 알려 주세요.

## 3. 소재

| 소재 | 쓰는 곳 | 이유 |
|---|---|---|
| **PETG** | 포드, 케이스, 보조 포드, 뚜껑, 버튼 하우징, 캡, 클립, 스트랩 고정구, FPC 덮개 | 질기고 약간 유연하며, 약 70–80 °C까지 견디고, 출력하기 쉽습니다 |
| **ASA** | 위와 같은 단단한 부품(고정구와 캡 제외)의 대안 | 매일 실외에서 쓰기에 자외선과 열에 가장 강합니다. 인클로저와 환기가 필요합니다. |
| **TPU 95A** | 새들, 진동 패드, 빗물 홈통, 배출구 | 부드럽고 잘 미끄러지지 않습니다. 헬멧 곡면을 따라 붙습니다. 머리에 닿아도 편합니다. 충격을 받으면 쉽게 눌립니다. |

### PLA를 쓰지 않는 이유

- **PLA는 약 55–60 °C에서 물러집니다.** 차 좌석이나 햇볕 드는 벤치에 둔 헬멧은 쉽게 이 온도를 넘습니다.
  Pi 케이스가 휘거나, 카메라 각도가 바뀌거나, 전방 라이다가 기울 수 있습니다. 그러면 센서가 보는 방향이
  티 나지 않게 달라집니다.
- PLA는 실외에서 부서지기 쉬워지고, 날카로운 조각으로 깨질 수 있습니다.
- PETG, ASA, TPU는 가격이 비슷하면서 이런 문제가 없습니다.

### 색상

- **밝은 색**(흰색, 밝은 회색, 노란색)은 햇볕을 받아도 덜 뜨거워집니다. Pi를 시원하게 유지하는 데 도움이
  됩니다. 메인 케이스 뚜껑 아래 쿨러의 여유 공간은 약 1.2 mm뿐입니다.
- **눈에 잘 띄는 노란색이나 주황색**은 운전자와 자전거 이용자가 착용자를 알아보는 데 도움이 됩니다.
- 가능하면 카메라 창 주변에는 **무광의 어두운 색** 소재를 쓰세요. 렌즈로 들어가는 반사광이 줄어듭니다.

## 4. 출력 설정과 서포트

기준 설정입니다(설계서 §10과 `hardware/README.md`).

| 설정 | 단단한 부품 (PETG/ASA) | TPU 부품 |
|---|---|---|
| 레이어 높이 | 0.2 mm | 0.2 mm |
| 벽(외벽) 수 | 4 | 3 |
| 채움(인필) | 25 % 자이로이드 (버튼 캡, 클립, FPC 덮개: 100 %) | 15 % (새들: 100 %) |
| 노즐 온도 | PETG 240 °C · ASA 250–260 °C | 220–235 °C |
| 베드 온도 | PETG 80 °C · ASA 90–100 °C | 40–60 °C |
| 속도 | 보통 | 느리게: 20–25 mm/s |
| 리트랙션 | 보통 | 없음 또는 아주 짧게 |
| 냉각 팬 | PETG 30–50 % · ASA 0–20 % | 50–100 % |
| 베드 접착 | PETG: 딱풀 또는 텍스처 PEI | 깨끗한 PEI |

### 서포트

- **곡면 바닥면과 곡면 뚜껑에는 빌드 플레이트에서만 올라오는 서포트가 필요합니다.** 트리(나무형) 또는 오가닉
  서포트를 권장합니다. 서포트는 새들 위에 놓이는 면이나, 아무도 만지지 않는 곡면 윗면에만 닿습니다.
- 해당 부품은 `front_pod_base`, `front_pod_cover`, `main_case_base`, `main_case_lid`, `aux_pod_base`,
  `aux_pod_lid`입니다. `button_module`은 비스듬한 스트랩 탭 아래에 아주 작은 서포트가 필요합니다.
- 나머지 돌출부는 모두 ≤ 45°입니다. 새들, 진동 패드, 고정구, 클립, FPC 덮개, 빗물 홈통, 배출구에는 서포트가
  필요 없습니다.
- **스트랩 구멍 안에는 서포트가 생기지 않게 하세요.** 출력 뒤 구멍에 남은 서포트나 첫 레이어 퍼짐(엘리펀트 풋)을
  깨끗이 없애세요.

도움말:

- **TPU:** 다이렉트 드라이브 익스트루더가 가장 좋습니다. 보우덴 방식 프린터에서는 아주 천천히 출력하세요.
- **ASA:** 인클로저 안에서, 사람이 없는 곳에서, 환기를 하면서 출력하세요. 출력할 때 유해 가스가 나옵니다.
- **필라멘트를 건조하세요.** 습기를 먹은 PETG와 TPU는 실 끌림이 심하고 부품이 약해집니다. 필라멘트 건조기에서
  55–65 °C로 4–6시간이면 보통 충분합니다.
- 설계서에 없는 값은 출발점일 뿐입니다. 필라멘트 제조사의 권장값을 먼저 따르세요.

| `rain_gutter_segment` | 세워서 | 없음 |
| `rain_nozzle_rear` | 세워서 | 없음 |

강도 참고: FDM 출력물은 레이어와 레이어 사이가 가장 약합니다. 스트랩 구멍과 고정구는 스트랩이 잡아당기므로,
레이어가 당기는 방향과 **평행**해야 합니다. 그래서 고정구는 눕혀서 출력합니다.

## 6. 높이와 무게

설계서 P2의 외피 위 높이 제한: **전방 센서 포드 ≤ 35 mm**, **메인 케이스 ≤ 40 mm**(액티브 쿨러를 단 Pi 5는
이보다 낮게 들어가지 않습니다), **나머지 모듈 ≤ 30 mm**. 아래는 내보낸 메시에서 잰 값입니다
(`hardware/README.md`, 3 mm 새들 포함).

| 모듈 | 차지 면적 (mm) | 외피 위 최대 높이 | 출력 무게 (추정) |
|---|---|---|---|
| 전방 센서 포드 (바닥 + 덮개) | 107.6 × 42 (스트랩 탭 포함 132) | 34.8 mm | ≈ 40 g PETG |
| 메인 케이스 (바닥 + 뚜껑) | 99.1 × 62.6 (탭 포함 가로 87.5) | 39.8 mm (가운데 34.6 mm) | ≈ 52 g PETG |
| 보조 포드 (바닥 + 뚜껑) | 98.6 × 37.6 (탭 포함 123) | 23.4 mm | ≈ 30 g PETG |
| 새들 (포드 / 케이스 / 보조 포드) | 위와 같음, 두께 3.0 mm | — | ≈ 13 / 18 / 11 g TPU |
| 버튼 모듈 + 캡 | 26 × 71 (탭 포함 96) | 캡 포함 ≈ 21 mm | ≈ 22 g PETG |
| 빗물 홈통 (조각 4개) + 배출구 | — | — | ≈ 86 g + 9 g TPU |

전자 부품까지 합친 추가 무게는 **빗물 홈통 없이 약 330 g**(예산 ≤ 380 g)이고, 홈통을 달면 약 425 g입니다.
무게는 메시 부피로 추정한 값이니 슬라이서에서 확인하세요.

## 7. 후가공과 가조립

1. **서포트와 브림을 없애세요.** 니퍼(플러시 커터)와 커터칼을 쓰고, 칼날은 손 반대쪽으로 움직이세요.
2. **스트랩 구멍을 정리하세요.** 스트랩 구멍은 모두 **21 × 3.2 mm**입니다. 20 mm 벨크로(찍찍이) 스트랩이
   힘주지 않고 통과해야 합니다. 남은 서포트, 실 찌꺼기, 엘리펀트 풋을 없애세요.
3. **바깥 모서리를 모두 둥글게 다듬으세요.** 바깥 모서리는 둥글게(필렛 ≥ 3 mm) 유지하고 뾰족한 곳이
   없어야 합니다(설계서 P2). 날카로운 모서리, 거스러미, 서포트 자국은 사포나 줄로 다듬으세요.
4. **나사 구멍.** 기본 설정에서 구멍은 셀프태핑 나사용 안내 구멍입니다. 나사를 한 번 끝까지 박았다가 풀어낸
   뒤 조립하세요. PETG에는 나사를 너무 세게 조이지 마세요. 황동 열압입 인서트를 쓰려면
   `lib/owsh_common.scad`에서 `use_heat_set = true`로 설정하고 다시 내보낸 뒤, 약 230 °C에서 인서트를 눌러 넣으세요.
5. **최종 조립 전에 전자 부품을 끼워 보세요.**
   - 액티브 쿨러를 단 라즈베리파이 5를 `main_case_base`의 스탠드오프에 올리고 뚜껑을 덮습니다. 쿨러가 뚜껑에
     닿으면 안 됩니다.
   - MPU-6050을 자리에 넣고, 3 mm LED를 안쪽에서 뚜껑에 눌러 끼웁니다.
   - `aux_pod_base`에 ULN2003을 받침에, USB 오디오 어댑터를 레일에 넣습니다.
   - 카메라 모듈 3 Wide를 카메라 자리에 넣습니다. 렌즈가 창 뒤 가운데에 와야 합니다.
   - TF-Luna 센서 두 개를 각자의 자리에 넣습니다. **TF-Luna 렌즈 구멍은 아무것도 가리면 안 됩니다.**
     남은 플라스틱 찌꺼기나 너무 낮게 내려온 빗물 턱도 마찬가지입니다.
   - 코인 모터를 옆에서 밀어 `haptic_pad` 홈에 넣습니다.
   - 12 mm 스위치를 `button_module`에 넣고 캡을 눌러 끼웁니다.
6. **각도를 확인하세요.** 포드를 헬멧에 올리고 머리를 수평으로 둔 상태에서, 휴대폰 기울기(수평계) 앱으로
   아래 보기 라이다 면이 수평보다 약 50° 아래를, 카메라가 약 10° 아래를 향하는지 확인하세요. 잰 값은 보정 때
   쓰니 적어 두세요([04 · 조립 가이드](04-조립가이드.md)의 보정 부분 참고).
7. **캡을 손으로 만져 보세요.** 눈을 감고 원(○, 점 1개), 세모(△, 점 2개), 네모(□, 점 3개)를 촉감만으로
   빠르게 구분할 수 있는지 확인하세요. 잘 구분되지 않으면 캡을 더 느린 속도와 더 얇은 레이어로 다시 출력하세요.
8. **출력한 부품을 헬멧에 접착제로 붙이지 마세요.** 부품은 스트랩과 3M 듀얼락으로만 고정합니다.

## 8. OpenSCAD로 STL 파일 만들기

저장소에 올라가 있는 STL 파일은 기본 파라미터로 만든 것입니다. 파라미터를 바꾸거나 부품을 개선할 때만
OpenSCAD가 필요합니다. OpenSCAD 2021.01 이상이 필요합니다.

1. openscad.org에서 OpenSCAD를 설치합니다(Windows, macOS, Linux). Debian/Ubuntu/Raspberry Pi OS에서는:
   ```bash
   sudo apt-get install -y openscad
   ```
2. 부품 하나 렌더링하기(저장소 최상위 폴더에서 실행):
   ```bash
   openscad -o hardware/stl/strap_anchor.stl hardware/openscad/strap_anchor.scad
   ```
3. 프로젝트 스크립트로 전체 렌더링하기. 스크립트는 `stl/<part>.stl`, `renders/<part>.png`, `stl/worn/`의
   착용 위치 메시, 조립 모습 3가지, `renders/render_log.txt`를 만듭니다. 전체 실행에는 약 17분이 걸립니다.
   ```bash
   hardware/scripts/render_all.sh                  # everything
   hardware/scripts/render_all.sh front_pod_base   # one part
   ```
   Windows에서는:
   ```powershell
   powershell -ExecutionPolicy Bypass -File hardware\scripts\render_all.ps1
   ```
4. `-D worn=true`를 붙이면 부품을 착용 위치로 내보냅니다. 이 메시는 미리보기 전용입니다.

부품 치수(Pi 5, 카메라 모듈 3 Wide, TF-Luna 등)도 파라미터이며, 설계서 §4.4에 정리되어 있고 라이브러리
파일에는 "verify"(확인 필요)로 표시되어 있습니다. **가지고 있는 부품을 캘리퍼스로 직접 재세요.** 카메라 렌즈
경통, TF-Luna 구멍과 창, Pi 5 쿨러 차지 면적, USB 포트 뭉치와 헤더 높이, GY-521 두께, ULN2003 보드와 오디오
어댑터 크기, 스위치 누름부, 코인 모터, 헬멧 테두리 두께를 확인합니다.

부품을 개선했다면 `.scad` 변경분과 다시 렌더링한 STL을 함께 커밋해 주세요. 그래야 CAD를 쓰지 않는 사람도
바로 출력할 수 있습니다. [CONTRIBUTING.md](../../CONTRIBUTING.md)를 참고하세요.

## 9. 문제 해결

| 문제 | 해 볼 것 |
|---|---|
| 포드나 케이스 양 끝 아래에 틈이 생김 | 외피 반경을 다시 재고 `pod_R` / `case_R_*` / `aux_R_*`를 설정한 뒤 다시 렌더링 |
| 곡면 바닥면에 서포트 자국이 남음 | 빌드 플레이트에서만 올라오는 트리 서포트 사용, 가볍게 사포질; 작은 자국은 새들이 가려 줌 |
| PETG가 벽 사이에 실처럼 늘어짐 | 필라멘트 건조, 온도 5 °C 낮추기, 리트랙션 약간 늘리기 |
| PETG 부품이 매끈한 PEI에 달라붙음 | 다음에는 딱풀을 분리층으로 바르거나 텍스처 시트 사용 |
| TPU가 익스트루더에서 막힘 | 속도 낮추기, 리트랙션 줄이거나 끄기, 아이들러 장력 풀기 |
| ASA 모서리가 들뜸 | 인클로저, 브림, 베드 온도 높이기, 바람 막기 |
| 스트랩이 구멍을 통과하지 않음 | 서포트와 엘리펀트 풋 제거, 줄로 구멍 다듬기 |
| 부품이 너무 빡빡함 | `clr`를 올리고(예: 0.4) 다시 렌더링 |
| 카메라나 라이다가 자리에 안 들어감 | 부품을 재고, 치수 파라미터를 조정한 뒤 다시 렌더링 |
| Pi 나사 구멍이 맞지 않음 | 구멍 간격 58 × 49 mm 확인, 배율 100 % 확인 |
| 쿨러가 뚜껑에 닿음 | 쿨러 모델과 `pi_cooler_rect` 파라미터 확인; 뚜껑이 팬을 누르는 상태로는 절대 가동하지 말 것 |
| 캡 모양이 잘 구분되지 않음 | 캡을 더 느리게, 0.12 mm 레이어로, 돌출 모서리와 점을 더 또렷하게 출력 |
