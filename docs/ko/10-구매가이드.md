## 주문 전에 꼭 알아야 할 7가지

1. **카메라는 반드시 "Camera Module 3 Wide"(모델명 SC1224)를 사세요.**
   일반형(75°), **NoIR**, **NoIR Wide**가 같은 목록에 나란히 있습니다.
   특히 디바이스마트는 2026-09-15 현재 Wide가 품절이고 바로 옆 **NoIR Wide만 구매 가능**합니다. NoIR은 적외선 필터가 없어 낮에 색이 틀어지니 사지 마세요.
2. **카메라 케이블은 따로 사야 합니다 (Pi 5용 22핀→15핀, 모델명 SC1129, 300mm).**
   Wide 카메라에 동봉된 케이블은 판매처마다 다르고, 15핀→15핀(Pi 4용)만 들어 있는 경우도 있습니다. 2~3천원이니 꼭 함께 주문하세요.
   엘레파츠는 이 케이블 이름이 "Camera Cable **Standard**"로 되어 있지만 실제로는 Pi 5용 SC1129입니다. "Display Cable"은 카메라에 쓸 수 없습니다.
3. **라이다는 "TF-Luna"여야 합니다.** 검색하면 TFmini Plus, TFmini-S, TF02 Pro가 섞여 나옵니다. 크기와 통신 방식이 달라 3D 부품에 맞지 않습니다.
   드론 카테고리의 CUAV "TF-Luna"는 약 3.5배 비싸니 피하세요.
4. **I2C 허브(Qwiic/STEMMA QT)는 사지 마세요.** 3.3V 전용이라 5V가 필요한 TF-Luna와 맞지 않습니다. **듀폰 분배 케이블**을 쓰세요.
5. **보조배터리는 출력 표에 "USB-C 5V⎓3A"가 적힌 제품만** 사세요. "PD 20W"라고만 적힌 제품은 5V에서 2A만 나오는 경우가 많고, 그러면 헬멧이 전원 부족 경고를 냅니다.
6. **골전도 헤드셋 플러그와 USB 오디오 어댑터 잭을 맞추세요.** 대부분의 헤드셋은 **4극 단일 플러그**(마이크 포함)입니다.
   아래 추천 어댑터는 헤드폰·마이크 **분리형 잭**이라 **4극→3극 2분배 젠더**가 함께 필요합니다.
7. **"ULN2003AP" / "ULN2003A(SMD)"는 칩 단품입니다.** 반드시 **드라이버 보드(모듈)**를 사세요.

## 택배를 받으면 바로 검수할 것

반품 기간 안에 확인해야 합니다. 특히 해외배송 상품은 반품이 안 됩니다.

- [ ] 라즈베리파이 박스에 **Raspberry Pi 5**와 RAM 용량(4GB/8GB)이 적혀 있다
- [ ] 쿨러 모델명 **SC1148**, 파이 5 전용
- [ ] 카메라 박스에 **Camera Module 3 Wide** 표기 (NoIR 아님). 렌즈가 일반형보다 넓고 볼록함
- [ ] 카메라 케이블 한쪽이 **좁은 22핀(0.5mm)**, 다른 쪽이 **넓은 15핀(1mm)**, 케이블에 "CAMERA" 인쇄, 길이 약 300mm
- [ ] 라이다 라벨에 **TF-Luna** (TFmini 아님), 6핀 커넥터, 케이블 동봉 여부 확인
- [ ] ULN2003은 칩이 아니라 **보드**(빨간 LED 4개와 핀 헤더가 있는 초록 기판)
- [ ] 택트스위치 높이 **7.3mm**
- [ ] 보조배터리 뒷면 출력 표에 **5V⎓3A**
- [ ] 마그네틱 케이블 **1.2m**, 데이터 전송 가능 표기
- [ ] 헤드셋 플러그와 오디오 어댑터(+젠더)가 실제로 맞물림
- [ ] 필라멘트가 **PETG(또는 ASA)**와 **TPU 95A**

모두 확인했으면 [02 · 배선 가이드](02-배선가이드.md)와 [03 · 3D 프린팅 가이드](03-3D프린팅가이드.md)로 넘어가세요.
